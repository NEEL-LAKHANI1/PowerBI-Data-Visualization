
# Power BI Data Visualization Project

## Project Overview
This project demonstrates various Power BI visualizations using the Superstore Sales dataset.

## Tools Used
- Power BI Desktop
- Microsoft Excel
- Superstore Dataset

## Visualizations
- Clustered Column Chart
- Clustered Bar Chart
- Stacked Column Chart
- 100% Stacked Column Chart
- Pie Chart
- Donut Chart
- Treemap
- Line Chart
- Area Chart
- Scatter Plot
- Gauge Chart
- Card
- Funnel Chart
- Waterfall Chart
- KPI
- Matrix
- Table
- Decomposition Tree
- Maps

## Files
- `PowerBI_Visuals.pbix` – Power BI dashboard
- `PowerBI_Visuals_Documentation.pdf` – Report explaining each visual
- `Dataset/` – Source dataset
